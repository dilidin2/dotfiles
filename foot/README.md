# Foot

Minimalist, fast terminal emulator for Wayland.

## Notes

- Font: JetBrains Mono Nerd Font (12pt) with Noto Color Emoji and Noto Sans Mono CJK as fallbacks
- 95% opacity (slight transparency)
- 5000 lines scrollback
- Copy/paste with `Ctrl+Shift+C/V`
- URL mode with `Shift+Alt+U`
- Shell is not hardcoded — uses your login shell automatically
