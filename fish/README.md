# Fish Shell

Configuration for the Fish shell.

## Features

- **Fastfetch banner** on startup (rendered with `tte` for gradient effect)
- **Custom prompt** showing user@host, path, git status, and exit code
- **Git prompt** enabled with dirty state, upstream, untracked files, stash state, and color hints
- **Aliases**:
  - `theme-switch` → launch theme switcher
  - `new-theme` → create a new theme

## Dependencies

- `fastfetch`
- `tte` (for gradient rendering of fastfetch output)
